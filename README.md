Projeto desenvolvido em Python com Flask para praticar a criação de uma API REST completa com persistência em SQLite.

A aplicação permite:

- cadastrar clientes manualmente;
- listar todos os clientes;
- buscar cliente por ID;
- atualizar cliente;
- deletar cliente;
- importar clientes de uma API externa e salvá-los no banco local.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- Requests

## Objetivo do projeto

Este projeto foi criado para praticar conceitos fundamentais de backend, como:

- criação de rotas REST;
- operações CRUD;
- validação de dados;
- integração com API externa;
- tratamento e normalização de dados;
- persistência em banco de dados relacional.

## Estrutura dos dados

Cada cliente possui os seguintes campos:

- `id`
- `nome`
- `email`
- `telefone`
